HTML

发表于 2025-11-12 更新于 2025-11-29 分类于 前端

HTML用于描述网页结构：

  • 超文本标记语言（Hyper Text Markup Language）
  • 它是一种标记语言，使用标记标签描述网页

基本语法

  • 标签分为双标签和单标签，标签名不区分大小写，推荐全部小写
  • 属性写在开始标签内，格式为name="value"
  • 注释格式为<!-- 注释 -->

基础结构

HTML文档主要分为三个部分：声明、头部和主体。

文档基本结构

标签

文本内容

标题：<h1>~<h6>

段落：<p>

强调：粗体<strong> <b>、斜体<em> <i>

删除：<del> <s>

插入：<ins> <u>

换行：<br/>

分隔线：<hr/>

上标：<sup> 下标：<sub>

短引用：<q> 块引用：<blockquote>

预格式化文本（保留格式）：<pre>

代码：<code>

高亮：<mark>

链接

<a>标签定义了一个超链接，href属性指定了目标URL。

target属性：定义链接的打开方式

  • _blank：在新窗口/标签页中打开
  • _self：在当前窗口/标签页中打开
  • _parent：在父级中打开
  • _top：在顶层打开

图像

width和height属性可以用来设置图像的宽高。

列表

分类：有序、无序、自定义列表

列表可以嵌套。

表格

表格较长时，可以使用表格结构标签划分区域：

  • <thead>：表格的表头
  • <tbody>：表格的主体区域
  • <tfoot>：表格的脚注

容器

通用

<div>：块级容器

<span>：内联容器

这两个标签都无语义，一般用于布局和应用样式。
