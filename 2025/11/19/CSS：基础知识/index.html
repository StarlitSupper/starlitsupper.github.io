HTML/CSS前端

CSS用于给HTML结构设置样式：

  • 层叠样式表（Cascading Style Sheets）
  • 它也是一种标记语言

优先级：行内样式>内部样式=外部样式

语法规范

CSS规则由两部分构成：

  • 选择器：找到需添加样式的元素
  • 声明块：设置具体的样式，声明的格式为name: value;

选择器优先级

行内 > id 选择器 > 类选择器 > 元素选择器 > 通配选择器

!important最超模，其他情况下，高层级优先，同层级依次向下比，全部等同的情况下看先后顺序。

其实鼠标在 VS Code 里悬停一下能看。

CSS特性

  1. 层叠性：发生样式冲突时，会根据选择器优先级，进行样式的层叠（其实就是覆盖）
  2. 继承性：元素会自动拥有父元素或者祖先元素设置的某些样式（text-…、font-…、line-…、color等），优先继承近的
  3. 优先级：这是一个权重的问题

单位

单位 含义
px 像素
% 百分比（相对父元素计算）
rem 相对于根元素的字体大小
em 相对元素font-size的倍数
vh 视口高度
vw 视口宽度

颜色

  1. 颜色名：直接使用颜色对应的英文单词

  2. RGB与RGBA：使用红绿蓝进行组合

  3. HEX与HEXA：同样使用红绿蓝进行组合

  4. HSL与HSLA：通过色相、饱和度、亮度来表示颜色

    • 色相：取值范围为0-360度

    • 饱和度：取值范围为0%-100%

    • 亮度：取值范围为0%-100%

字体属性

字体大小

不同浏览器的默认字体大小可能不同，最好确定明确值。

字体族

注意点：

  1. 使用英文名兼容性更好；
  2. 字体按顺序进行查找，最后一般会写上serif（衬线字体）或sans-serif（非衬线）

对<body>元素设置font-size和font-family就可以让全部元素继承。

字体风格

常用值：

  1. normal：默认值
  2. italic：字体自带斜体（推荐）
  3. oblique：强制倾斜

字体粗细

数值：100-300=lighter，400-500=normal，600以上=bold。

复合属性

格式要求：…… 字体大小 字体族（后两位必须有且顺序不能变）

文本属性

文本颜色

开发中用 RGB/RGBA 或 HEX/HEXA 比较多。

文本间距

属性值为px，正值间距增大，负值减小。

文本修饰

可选值：

  1. none：无装饰线（常用）
  2. underline：下划线（常用）
  3. overline：上划线
  4. line-through：删除线

可以搭配dotted（虚线）、wavy（波浪线）还有颜色使用。

行高

由于字体设计原因，文字在行中一般不是绝对垂直居中，全是文字时不太影响观感。

注意点：

  1. line-height过小时会产生重叠，最小值不能为负值
  2. line-height可以继承，最好设置数值（⚠百分比继承的是计算完的像素值），以免字体大小的差异导致观感差异大
  3. 不设置height时，会根据line-height计算高度

应用场景：

  1. 实现单行文字的垂直居中（不是绝对）
  2. 控制多行文字的行间距

背景属性

background-repeat的属性值：

  • repeat：默认，重复铺满整个元素
  • repeat-x：只在水平方向重复
  • repeat-y：只在垂直方向重复
  • no-repeat：不重复

background-position：

  • 关键字设置位置：如left top，只写一个值另一个方向取center
  • 长度指定坐标位置：以元素左上角为原点，两个值分别为x和y轴坐标，只写一个值y取center

鼠标

显示模式

  1. 块元素

    • 独占一行，从上到下排列
    • 默认宽度：撑满父元素
    • 默认高度：由内容撑开
    • 可以使用CSS设置宽高

  2. 行内元素

    • 不独占一行，容纳不下的会在下一行从左到右排列
    • 默认宽高都由内容撑开
    • 无法通过CSS设置宽高

  3. 行内块元素

    与行内元素相比，可以通过CSS设置宽高。

各元素的显示模式
  • 块元素（block）
    1. 主体结构标签：<html>、<body>
    2. 排版标签：<h1>-<h6>、<hr>、<p>、<pre>、<div>
    3. 列表标签：<ul>、<ol>、<li>、<dl>、<dt>、<dd>
    4. 表格相关标签：<table>、<thead>、<tbody>、<tfoot>、<tr>、<caption>
  • 行内元素（inline）
    1. 文本标签：<br>、<em>、<strong>、<sup>、<sub>、<del>、<ins>
    2. <a>和<label>
  • 行内块元素（inline-block）
    1. 图片：<img>
    2. 单元格：<th>、<td>
    3. 表单控件：<input>、<textarea>、<select>、<button>
    4. 框架标签：<iframe>
