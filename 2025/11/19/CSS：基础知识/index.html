CSS：基础知识

发表于 2025-11-19 更新于 2025-12-01 分类于 前端

CSS用于给HTML结构设置样式：

  • 层叠样式表（Cascading Style Sheets）
  • 它也是一种标记语言

语法规范

CSS规则由两部分构成：

  • 选择器：找到需添加样式的元素
  • 声明块：设置具体的样式，声明的格式为name: value;

编写位置

优先级：行内样式>内部样式=外部样式

在实际应用中最好使用外部样式，它能做到一套代码多页面复用，可维护性高。

CSS特性

  1. 层叠性：发生样式冲突时，会根据选择器优先级，进行样式的层叠（其实就是覆盖）
  2. 继承性：元素会自动拥有父元素或者祖先元素设置的某些样式（text-…、font-…、line-…、color等），优先继承近的
  3. 优先级：这是一个权重的问题

选择器优先级

行内 > id 选择器 > 类选择器 > 元素选择器 > 通配选择器

!important最超模，其他情况下，高层级优先，同层级依次向下比，全部等同的情况下看先后顺序。

可以不用自己算，鼠标在 VS Code 里悬停一下能看。

尽量保持最低水平的优先级，否则后续的覆盖就会变得很困难，基于这个原因，尽量不要使用!important和id选择器。

单位

单位 含义
px 像素
% 百分比（相对父元素计算）
rem 相对于根元素的字体大小
em 相对元素font-size的倍数
vh 视口高度
vw 视口宽度

颜色

大概看看，实际开发中直接按UI给的写。

  1. 颜色名：直接使用颜色对应的英文单词

  2. RGB与RGBA：使用红绿蓝进行组合

  3. HEX与HEXA：同样使用红绿蓝进行组合

  4. HSL与HSLA：通过色相、饱和度、亮度来表示颜色

    • 色相：取值范围为0-360度

    • 饱和度：取值范围为0%-100%

    • 亮度：取值范围为0%-100%

行高

由于字体设计原因，文字在行中一般不是绝对垂直居中，全是文字时不太影响观感。

注意点：

  1. line-height过小时会产生重叠，最小值不能为负值
  2. line-height可以继承，最好设置数值（⚠百分比继承的是计算完的像素值），以免字体大小的差异导致观感差异大
  3. 不设置height时，会根据line-height计算高度

应用场景：

  1. 实现单行文字的垂直居中（不是绝对）
  2. 控制多行文字的行间距

背景属性

background-repeat的属性值：

  • repeat：默认，重复铺满整个元素
  • repeat-x：只在水平方向重复
  • repeat-y：只在垂直方向重复
  • no-repeat：不重复

background-position：

  • 关键字设置位置：如left top，只写一个值另一个方向取center
  • 长度指定坐标位置：以元素左上角为原点，两个值分别为x和y轴坐标，只写一个值y取center

鼠标

显示模式

  1. 块元素

    • 独占一行，从上到下排列
    • 默认宽度：撑满父元素
    • 默认高度：由内容撑开
    • 可以使用CSS设置宽高

  2. 行内元素

    • 不独占一行，容纳不下的会在下一行从左到右排列
    • 默认宽高都由内容撑开
    • 无法通过CSS设置宽高

  3. 行内块元素

    与行内元素相比，可以通过CSS设置宽高。

各元素的显示模式
  • 块元素（block）
    1. 主体结构标签：<html>、<body>
    2. 排版标签：<h1>-<h6>、<hr>、<p>、<pre>、<div>
    3. 列表标签：<ul>、<ol>、<li>、<dl>、<dt>、<dd>
    4. 表格相关标签：<table>、<thead>、<tbody>、<tfoot>、<tr>、<caption>
  • 行内元素（inline）
    1. 文本标签：<br>、<em>、<strong>、<sup>、<sub>、<del>、<ins>
    2. <a>和<label>
  • 行内块元素（inline-block）
    1. 图片：<img>
    2. 单元格：<th>、<td>
    3. 表单控件：<input>、<textarea>、<select>、<button>
    4. 框架标签：<iframe>

盒子模型

组成

CSS会把所有HTML元素看成一个盒子，所有样式都基于这个盒子设置。

  • margin（外边距）：盒子和外界的距离
  • border（边框）：盒子的边框
  • padding（内边距）：紧贴内容的空白区域
  • content（内容）：元素中的文本或后代元素

盒子的大小 = content + 左右padding + 左右border

内容区

内容区主要的属性是width和height，加上前缀max或min的话就是字面意思，最大最小宽高。

需要设置最大最小宽高时，一般不直接指定宽高。

内边距

属性名 作用
padding-top 上内边距
padding-right 右内边距
padding-bottom 下内边距
padding-left 左内边距
padding 复合属性

padding复合属性规则：

  1. 只写一个值时，四个方向内边距一致
  2. 写两个值时，分别代表上下、左右
  3. 三个值时，分别代表上、左右、下
  4. 四个值时，按上、右、下、左的顺序设置

注意点：

  1. padding的值不能为负
  2. 行内元素左右padding没问题，上下不能完美设置；块级元素和行内块元素四个方向都没问题

边框

与前面相比，可以通过增加方向具体设置，如border-left-style。

外边距

属性名 作用
margin-left 左外边距
margin-right 右外边距
margin-top 上内边距
margin-bottom 下内边距
margin 复合属性

注意点：

  1. 子元素的margin参考父元素content计算（子元素在父元素的内容区内）
  2. 块级元素、行内块元素四个方向的margin都可以完美设置；行内元素只有左右margin可以完美设置
  3. margin的值可以是auto，给块级元素设置左右margin都为auto的话，它可以在父元素中水平居中
  4. margin可以取负值

溢出

设置溢出内容的处理方式：

overflow属性的常用取值：

  • visible：可见（直接溢出），默认值
  • hidden：隐藏，溢出内容直接截断
  • scroll：提供x和y轴滚动条（无论是否溢出，不推荐）
  • auto：不溢出时正常，溢出时进化成滚动条

overflow加上后缀-x和-y时，可以单独设置不同轴的溢出处理方式，但不推荐这么做，这两个东西不太稳定，一块用的时候不见得能获得预期效果。
