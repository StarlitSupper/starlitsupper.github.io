图像增强与空间滤波

发表于 2025-11-27 更新于 2025-12-02 分类于 学习笔记

空间域图像增强

图像增强分为两类：

  1. 空间域增强：对图像的像素直接处理
  2. 频域增强：修改图像的傅里叶变换

空间域增强：$g(x,y)=T[f(x,y)]$

  • f(x,y)是原图像
  • g(x,y)是处理后的图像
  • T是作用于f的操作，定义在(x,y)的邻域

空间域增强的简化形式：$s=T(r)$

  • r是f(x,y)在任意点(x,y)的灰度级
  • s是g(x,y)在任意点(x,y)的灰度级

目的与意义：

  1. 便于人和机器发现图像特征，易于后续处理
  2. 改善图像的视觉效果
  3. 强调图像的整体或局部特性，更容易获得图像中的有用信息
  4. 应用于机器学习

点运算

反转变换

反转变换：$s=(L-1)-r$

  • $[0,L-1]$是图像的灰度级。
  • 作用：白的变黑，黑的变白

对数变换

对数变换：$s=c\ log(1+r)$

  • 在公式里，$c$是常数，$r≥0$。

使用场景：原图动态范围太大，超出某些显示设备允许的动态范围，直接使用原图时，一部分细节可能丢失。

解决方案：对原图进行灰度压缩，如对数变换。

幂次变换

幂次变换：$s=cr^\gamma$

  • $c$和$γ$是正常数
  • $γ<1$提高灰度级，在正比函数上方，使图像变亮
  • $γ>1$降低灰度级，在正比函数下方，使图像变暗

（一般处理的是归一化后的灰度值，所以才是这个逻辑）

分段线性变换

分段线性变换：将整个灰度范围划分成几个连续的区间，在每个区间内使用不同的线性函数进行变换。

  • 不同于全局变换，允许对图像中特定灰度范围的对比度进行调整
  • 斜率＞1时增强对比度，斜率＜1时压缩对比度

对比度拉伸：提高图像处理时灰度级的动态范围

灰度级切片

从整个图像的灰度范围中，“切出”一个特定的子区间（关心范围），关心范围指定较高值，其它指定较低值或保持不变。

位平面切片

根据图像的位数分解成对应的位平面（如8位灰度图像可以划分为位平面0到位平面7），每个位平面只包含原图中所有像素在某个bit位上的信息。

简单点来说的话，位平面就是只保留对应位的值的二值图像。

像在下图中，位平面0就是所有像素最低位的集合，以此类推。

作用：

  • 通过对特定位提高亮度，改善图像质量
  • 较高位（如前四位）包含大多数视觉重要数据
  • 较低位（如后四位）对图像的微小细节有作用
  • 分解为位平面，可以分析每一位在图像中的相对重要性

代数运算

  • 加法：$C(x,y)=A(x,y)+B(x,y)$

    主要应用：

    • 去除叠加性噪声

      对于原图像$f(x,y)$，有一个噪声图像集${g_i(x,y)}，i=1,2,\ldots,N$。

      其中：$g_i(x,y)=f(x,y)+h(x,y)_i$

      假设噪声$h(x,y)$均值为0，且互不相关，$N$个图像的均值定义为：$$g(x,y)=\frac{1}{N}(g_0(x,y)+g_1(x,y)+\ldots+g_N(x,y))$$

      期望值$E(g(x,y))=f(x,y)$

      上述图像均值将降低噪声的影响。

    • 生成图像叠加效果

      对于两个图像$f(x,y)$和$h(x,y)$的均值有：$g(x,y)=\frac{1}{2}f(x,y)+\frac{1}{2}h(x,y)$

      推广这个公式为：$g(x,y)=\alpha f(x,y)+\beta h(x,y)$，其中$\alpha+\beta=1$

      可以得到各种图像合成的效果，也可以用于两张图片的衔接

  • 减法：$C(x,y)=A(x,y)-B(x,y)$

    主要应用：

    • 显示两幅图像的差异，检测同一场景两幅图像之间的变化
    • 去除不需要的叠加性图案
    • 图像分割

  • 乘法：$C(x,y)=A(x,y)*B(x,y)$

    主要应用：

    • 图像的局部显示：用二值蒙板图像与原图像做乘法

  • 除法：$C(x,y)=A(x,y)/B(x,y)$

    一幅图像取反和另一幅图像相乘。

    主要用于：

    • 设备校正
    • 图像差异的比较

逻辑运算

  • 非

    灰度图像：$g(x,y)=255-f(x,y)$

    二值图像：$g(x,y)=1-f(x,y)$

    主要应用：

    • 获得一个阴图像
    • 获得一个子图像的补图像

  • 与

    $g(x,y)=f(x,y)\land h(x,y)$

    主要应用：合并子图像

  • 或

    $g(x,y)=f(x,y)\lor h(x,y)$

    主要应用：合并子图像

  • 异或

    $g(x,y)=f(x,y)\oplus h(x,y)$

    主要应用：找不同，显示两幅图像的差异部分

直方图运算

直方图定义

图像直方图：图像像素强度分布的统计图表，反映了图像对比度、亮度和强度分布等信息。（强度：比如说灰度级）

更直白点说就是统计不同取值的像素有多少个的图。

定义：

  • 非归一化直方图

    一个灰度级在范围$[0,L-1]$的数字图像的直方图是一个离散函数$h(r_k)=n_k$

    $n_k$是图像中灰度级为$r_k$的像素的个数，$r_k$是第$k$个灰度级，$k=0,1,2,\ldots,L-1$。

    由于$r_k$的增量是1，直方图可表示为$p(k)=n_k$，即图像中不同灰度级像素出现的次数。

  • 归一化直方图

    一个灰度级在范围$[0,L-1]$的数字图像的直方图是一个离散函数$p(r_k)=\frac{h(r_k)}{MN}=\frac{n_k}{MN}=\frac{n_k}{n}$

    $M$、$N$是图像的行数与列数，$n$是图像的像素总数，$n_k$是图像中灰度级为$r_k$的像素个数，$r_k$是第$k$个灰度级，$k=0,1,2,\ldots,L-1$

    经过比较，归一化直方图：

    • 使函数值正则化到$[0,1]$区间，成为实数函数
    • 函数值的范围与像素的总数无关
    • 给出灰度级$r_k$在图像中出现的概率密度统计

直方图均衡化

目的：把原始图像的直方图变为均衡分布的形式，增加像素灰度值的动态范围，从而增强图像整体对比度。

方法：使用灰度级变换$s=T(r)$，$0\leq r \leq 1$

此时需要满足两个条件（归一化）：

  1. $T(r)$在区间$0\leq r \leq 1$内为单值且单调递增（保证原图各灰度级在变换后仍保持次序）
  2. 当$0\leq r \leq 1$时，$0\leq T(r) \leq 1$（保证变换前后灰度值动态范围的一致性）
