CSS：浮动与定位

发表于 2025-11-29 更新于 2025-12-01 分类于 前端

浮动

浮动是CSS中的一种布局方式，最开始是为了实现文字环绕图片，后面有段时间被广泛用于网页布局。

语法：

给图片设置float: left;，此时可以看到效果：

核心特性

  1. 脱离文档流

    文档流（Normal Flow）：元素按照HTML中的顺序自然排列。

    浮动元素会脱离正常的文档流，但不会完全脱离，基于它的原始目的，后面的行内元素（如文本）会环绕在浮动元素周围。

  2. 元素排列

    浮动元素会尽量向指定方向移动，直到碰到父元素边界或其他的浮动元素，多个浮动元素会水平排列。

  3. 收缩包裹

    浮动后，默认宽高都是被内容撑开的，可以设置宽高（无论浮动前的显示模式）

  4. 不会margin合并与塌陷，可以完美设置四个方向的margin与padding

  5. 没有行内块的空白问题，浮动元素互相贴靠

影响与解决方案

  • 对兄弟元素：后面的兄弟元素会占据浮动元素之前的位置，对前面的文档流无影响
  • 对父元素：元素浮动后无法撑起父元素高度，导致父元素高度塌陷，但仍受父元素宽度束缚

针对父元素塌陷问题，有以下解决方案：

  1. 给父元素设置高度（治标不治本）
  2. 给父元素也一块设置浮动（会有其他影响）

很显然前面两个基本上在实际上是用不得了，所以就需要清除浮动，也就是让元素不受前面浮动元素影响，强制回到正常文档流。

  1. 父元素添加overflow: hidden;

    创建了BFC，会包含内部所有浮动元素参与高度运算。

    内容增多时可能会导致内容被隐藏掉，无法显示溢出元素，不推荐使用。

    在最后一个标签后面，新加一个标签，给它设置clear: both;，但是不符合语义化原则，还要手动管理很麻烦，不推荐

浮动布局原则：设置浮动时，兄弟元素要么全浮动，要么全不浮动。

定位

CSS定位用于控制元素在页面上的精确位置。

position: static;是它的默认值（静态定位），此时元素在正常的文档流中排列。

相对定位

相对于元素自身原来位置进行偏移：

可以使用left、right、top、bottom四个属性调整位置。

特点：

  1. 不会脱离文档流，只是视觉效果的变化，原位置空间仍然被占用
  2. 定位元素的显示层级比普通元素高，两个定位元素z-index相同时按文档流顺序，后写的覆盖在先写的上面
  3. left和right不能一起设置，top和bottom同理
  4. 相对定位的元素能继续浮动和通过margin调整位置，但不推荐

包含块：

  • 对未脱离文档流的元素：就是父元素
  • 对脱离文档流的元素：第一个拥有定位属性的祖先元素（初始包含块：页面，尺寸等于视口）

特点：

  1. 脱离文档流，对后面的兄弟元素和父元素有影响
  2. 绝对定位和浮动不能同时设置，冲突时浮动失效
  3. 可以通过margin调整位置，还是不推荐
  4. 元素（行内、行内块、块级）设置为绝对定位之后，都会变成定位元素（默认宽高被内容撑开，宽高可自由设置）

一般会通过子绝父相来进行设置。

定位层级

  1. 定位元素的显示层级比普通元素高，定位默认的显示层级一致
  2. 位置重叠时，文档流中后写的定位元素会显示在前面的元素之上
  3. 可以通过z-index调整层级（定位元素），值越大层级越高，没有单位
  4. z-index大的没有覆盖z-index小的元素时，检查包含块层级！
