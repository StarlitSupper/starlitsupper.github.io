CSS：Flex布局

发表于 2025-12-17 更新于 2025-12-18 分类于 前端

概述

Flexible Box 模型，通常被称为 flexbox，是一种一维的布局模型，它一次只能处理一行或者一列上的元素布局。

采用 flexbox 的区域就是 flex 容器，通过将 display 值设置为 flex 或 inline-flex 来创建。此时 flex 容器中的子元素会变为 flex 元素（项目）。

下面左图是标准文档流中块级元素纵向排列的效果，开启 flex 容器后效果如右图：

flex 布局理解的关键点就是两根轴线——**主轴**和**交叉轴**。

交叉轴垂直于主轴，因此调整主轴时交叉轴就会跟着变。

核心知识

容器属性

flex-direction

  • row：默认值，水平方向正向排列
  • row-reverse：水平方向反向排列
  • column：垂直方向正向排列
  • column-reverse：垂直方向反向排列

其实就是定义主轴方向，从而控制 flex 项目的排列方向。

flex-wrap

  • nowrap：默认值，不换行
  • wrap：换行

有个简写属性 flex-flow 可以把 flex-direction 和 flex-wrap 按顺序写一块。

justify-content

  • flex-start：对齐主轴起始位置
  • flex-end：对齐主轴终止位置
  • center：主轴居中
  • space-between：两端对齐，项目间等距
  • space-around：每个项目的左右边距相等，与边的距离为 x，项目间距离为 2x
  • space-evenly：完全等距

用于控制主轴方向上的对齐方式。

align-items

  • stretch：默认值，拉伸（没设置对应宽高才会出现）
  • flex-start
  • flex-end
  • center
  • baseline：基线对齐，基本不用

用于控制单行内项目交叉轴方向上的对齐方式。

align-content

  • flex-start
  • flex-end
  • center
  • space-between
  • space-around
  • space-evenly

用于控制交叉轴方向上多行的对齐方式。

项目属性

order

写在项目中可以调整 flex 项目的顺序，值必须为数字，可以为负数。

order 属性的默认值为 0，值越小排得越靠前，值越大越靠后。

flex

flex 是 flex-grow、flex-shrink 和 flex-basis 的简写属性。

flex-grow：伸展系数，默认值为 0（有剩余空间时）

flex-shrink：收缩系数，默认值为 1（空间不够时）

flex-basis：指定项目在主轴方向的初始大小，默认值为 auto，优先级比宽高大

有个很常用的值是 flex: 1; （三个属性依次为 1 1 0%），给每个项目都安排上这个就实现完全等分了。

align-self

用于控制单个项目的交叉轴对齐方式，会覆盖 align-items 所设置的默认对齐方式。可选值和 align-items 基本一致。
