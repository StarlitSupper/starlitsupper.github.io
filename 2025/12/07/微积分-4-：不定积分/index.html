微积分(4)：不定积分

发表于 2025-12-07 更新于 2025-12-17 分类于 数学

概念

  • 原函数

    $F’(x) = f(x)$，此时$f(x)$为$F(x)$的导函数，$F(x)$则是$f(x)$的一个原函数

  • 不定积分

    $f(x)$在区间$I$上所有原函数的集合，称为$f(x)$在$I$上的不定积分，记为：
    $\int f(x)\ dx = F(x) + C$

    其实就是求取所有原函数的一种运算方法

函数奇偶性的变化：

  1. 微分方向

    $F(x)$奇函数$\Rightarrow$$f(x)$偶函数；$F(x)$偶函数$\Rightarrow$$f(x)$奇函数

  2. 积分方向

    $f(x)$奇函数$\Rightarrow$$F(x)$偶函数；$f(x)$偶函数$\Rightarrow$$F(x)$未必是奇函数

    不定积分的结果要$+C$，相当于进行了上下平移，此时只有一个函数在原点函数值为$0$

性质

  1. 线性运算性质
    • 常数因子可提：$\int kf(x)\ dx = k\int f(x)\ dx$（$k$为非零常数）
    • 和差积分：$\int [f(x) \pm g(x)]\ dx = \int f(x)\ dx \pm \int g(x)\ dx$
  2. 积分与微分的互逆性
    • $\frac{d}{dx}[\int f(x)\ dx] = f(x)$或$d[\int f(x)\ dx] = f(x)\ dx$（积分后求导，还原被积函数）
    • $\int F’(x)\ dx = F(x) + C$或$\int dF(x) = F(x) + C$（求导后积分，加积分常数）

计算

基本积分表

  • $\int 0\ dx = C$
  • $\int k\ dx = kx + C$（$k$为常数）
  • $\int x^n\ dx = \frac{x^{n+1}}{n+1} + C$（$n \neq -1$）
  • $\int \frac{1}{x}\ dx = \ln|x| + C$（$n=-1$ ）
  • $\int e^x\ dx = e^x + C$
  • $\int a^x\ dx = \frac{a^x}{\ln a} + C$（ $a>0$，$a\neq1$ ）
  • 正弦： $\int \sin x\ dx = -\cos x + C$
  • 余弦： $\int \cos x\ dx = \sin x + C$
  • 正切： $\int \sec^2 x\ dx = \tan x + C$
  • $\int \frac{1}{\sqrt{1-x^2}}\ dx = \arcsin x + C = -\arccos x + C $
  • $\int \frac{1}{1+x^2}\ dx = \arctan x + C = -\text{arccot} x + C$

第一类换元法

本质：凑微分法

利用复合函数求导逆运算，将积分凑成$\int f(u)du$，套用公式后再还原$u = \varphi(x)$ 。

例：
$$
\int \cos 2x \ dx
= \frac{1}{2} \int \cos 2x \cdot d(2x)
= \frac{1}{2} \int \cos t \ dt
= \frac{1}{2} \sin t + C
= \frac{1}{2} \sin 2x + C
$$

第二类换元法

需要使用的显著标志：有一个比较复杂的根式

  1. 三角代换

    例：$\int \sqrt{1-x^2} , dx$

    令 $x = \sin\theta$，则$dx = \cos\theta , d\theta$，且$\sqrt{1-x^2} = \sqrt{1-\sin^2\theta} = \cos^2\theta$

    则$I=\int \cos^2\theta \ d\sin\theta$

    $=\int \cos^2\theta \ d\sin\theta$

  2. 无理根式换元

    例：$\int \frac{\sqrt{x + 1}}{x}\ dx$

    $= \int \frac{t}{t^2 - 1} \cdot 2t \ dt$（$t=\sqrt{x + 1}$）

    $= 2\int \frac{t^2}{t^2 - 1}\ dt$

    $= 2\int \left(1 + \frac{1}{t^2 - 1}\right)\ dt$

    $= 2\left[ t + \frac{1}{2}\ln\left|\frac{t - 1}{t + 1}\right| \right] + C$

    $= 2\sqrt{x + 1} + \ln\left|\frac{\sqrt{x + 1} - 1}{\sqrt{x + 1} + 1}\right| + C$

分部积分法

公式：$\int u \cdot dv = uv - \int v \cdot du$

本质

分部积分法是基于求导的乘法运算法则推导的：

$[f(x) \cdot g(x)]’ = f’(x)g(x) + f(x)g’(x)$

$f(x) \cdot g(x)=\int f’(x)g(x) \ dx+ \int f(x)g’(x) \ dx=\int g(x) \ df(x)+\int f(x) \ dg(x)$

最后移项就可以得到：

$\int f(x)\ dg(x)=f(x)\cdot g(x)-\int g(x)\ df(x)$

令$u=f(x)$，$v=g(x)$即可获得公式形式。

使用经验：“反对幂三指”，靠前的优先放在后面

例：$\int lnx \ dx$

$=x\cdot lnx-\int x\cdot d(lnx)$

$=x\cdot lnx-\int x\cdot \frac{1}{x}\ dx$

$=xlnx-x$
