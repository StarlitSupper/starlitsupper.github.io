JavaScript：基础

发表于 2025-12-18 更新于 2025-12-19 分类于 前端

JavaScript 是一门跨平台、面向对象的脚本语言，可以实现网页的交互。

引入位置：可以在 <head> 标签和 <body> 标签内引入，但最好是在 <body> 的末尾，这样可以确保 JS 引入时，HTML 元素已完全加载。

组成：ECMAScript、Web APIs（DOM、BOM）

变量与类型

声明

JavaScript 有三种声明方式：

  • var ：声明一个函数作用域或全局作用域的变量
  • let：声明一个块级作用域的局部变量
  • const：声明一个块级作用域的只读命名常量，必须初始化

数据类型

基本数据类型：

  • Number：数字型（整数或浮点数）
  • String：字符串
  • Boolean：布尔型，true 和 false
  • undefined：未定义值
  • null：表示空值，但对它使用 typeof 时，会返回 object

前面的都比较常见，后面还加了两个基本数据类型：

  • Symbol：唯一标识符
  • BigInt：任意精度的整数

引用数据类型：Object

可以使用 typeof 运算符来确定类型，但是 typeof null 是历史遗留问题没啥办法解决。

数据类型转换

JS 变量的类型在运行时确定，且可以动态改变，因此可以通过重新赋值来进行类型转换。

隐式转换：

  • 字符串 + 数字型时，会转换为字符串的拼接
  • 其他时候一般是字符串转换为数字型进行运算
  • 字符串前面单加一个 + 会自动转换为 Number 型

显式转换：

  • Number()：转换为数字型
  • Boolean()：转换为布尔型
  • parseInt()：字符串或数字只保留整数部分，参数可选（进制），跟下面那个都只能处理开头
  • parsseFloat()：返回浮点数

其实还有别的，这里就先不提了。

运算符

和其他编程语言差不多：

算术运算符：+、-、*、/、%，特别注意 ** （指数运算）

赋值运算符：=、+=、-= 等

一元运算符：++、--

比较运算符：>、>=、<、<=

  • 注意点：==（值相等）、!=（宽松不等）、===（类型和值全等）、!==（严格不等）

逻辑运算符：&&、||、!

三元运算符：条件?表达式1:表达式2

函数

定义

函数是可重复使用的代码块，用于执行特定任务。

传统的函数定义由 function 关键字、函数名称、参数列表和函数体组成。

return 用来设置函数的返回值，没有时返回 undefined。

调用的时候就按照对应格式调就行：

函数的命名规范：小驼峰命名法，前缀最好用动词。

比较常用的动词约定：

  • can：判断是否可执行某个动作
  • has：判断是否含有某个值
  • is：判断是否为某个值
  • get：获取某个值
  • set：设置某个值
  • load：加载某些数据

需要传参的时候，就要设置函数的参数，实参可以少于形参，未赋值的以 undefined 代入。

JS 解释器会将函数声明提升到当前作用域的顶部，调用时位置在 函数声明上面也可以正常运行。
