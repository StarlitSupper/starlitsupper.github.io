CSS：Grid布局

发表于 2025-12-18 更新于 2025-12-21 分类于 前端

Grid 布局是一种二维布局模型，可以通过定义行和列来精确控制网页元素的位置和尺寸，还能实现响应式设计。

实际开发中经常将 Flexbox 和 Grid 混用，单行布局用 Flex，多行或响应式用 Grid。

基本概念

在 Grid 布局里，有些属性和概念可以类比 Flex 布局进行理解。

  • 容器：设置 display: grid 或 display: inline-grid 开启 Grid 布局的父元素

    Grid 布局开启后，创建了一个只有一列的网络，因此此时不会有明显变化。

  • 项目：Grid 布局中每个网格单元格内部放置的元素

  • 网格区域：一个或多个单元格组成的矩形区域

  • 间距：网格轨道间的距离

  • 网格线：划分网格结构的隐形参考线，从边上开始算，起始编号为 1，可以看下图

容器属性

行列划分

核心属性就两个：grid-template-rows（行高）和 grid-template-columns（列宽）。

如果要实现那种只限制行/列的，另一个属性就别写（写了也是写默认值 auto）。

这里属性值的写法非常多：可以用 px、%、auto 还有一些很好用的单位和函数，下面提一下。

  • fr：分数单位，相当于一个加权系数，独属于 Grid 布局

  • 使用 repeat() 简化重复定义：

    第一个参数为重复次数，第二个参数为重复值。

  • 使用 minmax() 弹性分配：

    minmax() 定义了一个可变的尺寸范围，空间充足时按最大的来，不足时按比例缩小，直到最小值停止变化。

  • auto-fill 和 auto-fit（自动填充）：

    auto-fill 总是创建尽可能多的轨道（可能空着），auto-fit 只创建有内容的轨道并拉伸填充空间。

    如果单给 px 的话，其实没啥区别，轨道的道理是一样的，但是宽度定死了没有变化的空间。写 fr 的话浏览器没办法算最小宽度会直接占一行。
